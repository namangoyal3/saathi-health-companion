1. System overview
Saath is a voice-and-message AI health companion composed of three synchronous paths (Telegram reminder loop, IVR escalation loop, lab ingestion) and two asynchronous paths (daily brief cron, Doctor Visit Report on demand). All paths share a common Postgres data store, a per-user filesystem memory store, and a pool of LLM-powered sub-agents orchestrated by a Supervisor.
Design principles
Haiku 4.5 on the hot path (voice and chat turns). Opus 4.7 on the deep path (labs, DDI, longitudinal synthesis, reports).
Every clinical output is routed through the safety-gatekeeper subagent before reaching a user.
Every inbound and outbound message is logged to Langfuse with user_id, agent, tool calls, tokens, cost.
Schemas are forward-compatible between Phase 1 fixture and Phase 2 real wearable streams.
The filesystem memory store is the source of truth for user profile; Postgres is the source of truth for events.

2.1 Postgres schema (core DDL)
-- 001_init.sql
CREATE EXTENSION IF NOT EXISTS pgcrypto;
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
 
-- Identities
CREATE TABLE app_user (
  id           UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  role         TEXT NOT NULL CHECK (role IN ('senior','guardian')),
  full_name    TEXT NOT NULL,
  dob          DATE,
  phone_e164   TEXT NOT NULL UNIQUE,
  tg_chat_id   BIGINT UNIQUE,
  language     TEXT NOT NULL DEFAULT 'hi',      -- 'hi' | 'ta' | 'en'
  timezone     TEXT NOT NULL DEFAULT 'Asia/Kolkata',
  created_at   TIMESTAMPTZ NOT NULL DEFAULT now()
);
 
-- Senior <-> Guardian relationship
CREATE TABLE care_relationship (
  senior_id    UUID REFERENCES app_user(id) ON DELETE CASCADE,
  guardian_id  UUID REFERENCES app_user(id) ON DELETE CASCADE,
  PRIMARY KEY (senior_id, guardian_id),
  consent_matrix JSONB NOT NULL DEFAULT '{}'::jsonb,
  created_at   TIMESTAMPTZ NOT NULL DEFAULT now()
);
 
-- Medications (active + historical)
CREATE TABLE medication (
  id              UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  senior_id       UUID NOT NULL REFERENCES app_user(id) ON DELETE CASCADE,
  generic_name    TEXT NOT NULL,     -- 'Metformin'
  brand_name      TEXT,              -- 'Glycomet'
  dose_mg         NUMERIC,
  dose_unit       TEXT NOT NULL,     -- 'mg' | 'mcg' | 'IU'
  schedule_rrule  TEXT NOT NULL,     -- RFC 5545 RRULE; e.g., 'FREQ=DAILY;BYHOUR=9,21'
  instruction     TEXT,              -- 'fasting', 'with food', 'HS'
  active_from     DATE NOT NULL DEFAULT CURRENT_DATE,
  active_until    DATE,              -- NULL = still active
  created_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);
 
-- Every reminder fire + its outcome
CREATE TABLE med_reminder_event (
  id            UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  senior_id     UUID NOT NULL REFERENCES app_user(id),
  medication_id UUID NOT NULL REFERENCES medication(id),
  scheduled_for TIMESTAMPTZ NOT NULL,
  channel       TEXT NOT NULL,         -- 'telegram' | 'ivr_call' | 'system'
  event         TEXT NOT NULL,         -- 'sent' | 'taken' | 'snoozed' | 'skipped' | 'auto_skip' | 'taken_via_ivr'
  snooze_count  INT NOT NULL DEFAULT 0,
  skip_reason   TEXT,
  acknowledged_at TIMESTAMPTZ,
  payload       JSONB NOT NULL DEFAULT '{}'::jsonb,
  created_at    TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX ON med_reminder_event (senior_id, scheduled_for DESC);
 
-- Lab panels (one row per biomarker value)
CREATE TABLE lab_panel (
  id             UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  senior_id      UUID NOT NULL REFERENCES app_user(id),
  collection_date DATE NOT NULL,
  lab_chain      TEXT NOT NULL,       -- 'Thyrocare' | 'Dr Lal' | 'Metropolis' | 'SRL'
  source_pdf_key TEXT,                 -- R2 object key
  parse_confidence NUMERIC,            -- 0..1 mean across biomarkers
  created_at     TIMESTAMPTZ NOT NULL DEFAULT now()
);
 
CREATE TABLE lab_biomarker (
  id           UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  lab_panel_id UUID NOT NULL REFERENCES lab_panel(id) ON DELETE CASCADE,
  biomarker    TEXT NOT NULL,         -- 'eGFR'
  value        NUMERIC NOT NULL,
  unit         TEXT NOT NULL,
  ref_low      NUMERIC,
  ref_high     NUMERIC,
  flag         TEXT,                   -- 'low' | 'high' | 'normal' | NULL
  created_at   TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX ON lab_biomarker (lab_panel_id, biomarker);
 
-- IVR call records
CREATE TABLE ivr_call_log (
  id              UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id         UUID NOT NULL REFERENCES app_user(id),
  provider        TEXT NOT NULL,      -- 'exotel' | 'twilio'
  provider_call_id TEXT NOT NULL,
  direction       TEXT NOT NULL,      -- 'outbound' | 'inbound'
  trigger_type    TEXT NOT NULL,      -- 'missed_med' | 'urgent_alert' | 'wellness_check'
  language        TEXT NOT NULL,
  script_template TEXT NOT NULL,      -- key into IVR_SCRIPTS registry
  dtmf_responses  JSONB NOT NULL DEFAULT '[]'::jsonb,
  duration_sec    INT,
  status          TEXT NOT NULL,      -- 'queued' | 'ringing' | 'in_progress' | 'completed' | 'failed' | 'no_answer'
  retry_count     INT NOT NULL DEFAULT 0,
  started_at      TIMESTAMPTZ,
  ended_at        TIMESTAMPTZ,
  created_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);
 
-- Telegram inbound free-text + attachments
CREATE TABLE telegram_inbound (
  id          UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id     UUID NOT NULL REFERENCES app_user(id),
  tg_message_id BIGINT NOT NULL,
  text        TEXT,
  voice_file  TEXT,                     -- R2 key if voice note
  transcript  TEXT,                     -- STT result
  intent      TEXT,                     -- classifier output: 'question'|'symptom'|'ack'|'other'
  created_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);
 
-- Everything an agent flags
CREATE TABLE agent_flag (
  id         UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  senior_id  UUID NOT NULL REFERENCES app_user(id),
  source     TEXT NOT NULL,           -- 'DDIAgent' | 'LabAgent' | 'SymptomAgent' | ...
  level      TEXT NOT NULL,           -- 'LOW' | 'MEDIUM' | 'HIGH' | 'URGENT'
  title      TEXT NOT NULL,
  body       TEXT NOT NULL,
  context    JSONB NOT NULL DEFAULT '{}'::jsonb,
  resolved_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX ON agent_flag (senior_id, created_at DESC);
 
-- Daily summary snapshot (source for briefs)
CREATE TABLE daily_summary (

  period_end   DATE NOT NULL,
  pdf_r2_key   TEXT NOT NULL,
  share_url    TEXT,

  payload      JSONB NOT NULL,         -- full report structure

4.2.2 System prompt (abridged)
You are the DDISubAgent for Saath, an AI health companion for aging Indian parents.
 
Your job is to evaluate drug-drug interactions (DDI) and drug-organ interactions for
an Indian senior with multiple chronic conditions, given:
  - the full current medication regimen (generic + brand + dose + schedule)
  - the most recent lab panel (esp. renal: eGFR, creatinine)
  - recent reported symptoms with timing
  - historical DDI flags from prior evaluations
 
You reason step-by-step through each potential interaction before flagging it. You
ESCALATE a flag level when a pharmacological risk is CORROBORATED by a symptom
pattern (e.g., Amlodipine+Telmisartan + post-AM-dose dizziness >= 3 times => elevate
to HIGH).
 
You MUST NOT:
 - Recommend a specific dose change (e.g., "reduce to 2.5mg"). Describe the risk only.
 - Use diagnostic language ("the patient has X"). Use "associated with" or "consistent with".
 - Omit the "physician_review_required": true field on any flag of MEDIUM or above.
 
Flag level taxonomy:
  LOW     - informational; included in brief only if clustered.
  MEDIUM  - physician should know at next visit; included in Doctor Report.
  HIGH    - flag on next brief; included in Doctor Report exec summary.
  URGENT  - triggers IVR Flow B (parallel outbound to senior + guardian).
 
Output STRICT JSON matching schema DDI_OUTPUT_V1 (no prose, no markdown fences).

4.3 safety-gatekeeper — final egress filter
Every string destined for a user (Telegram, IVR TTS, dashboard toast, PDF body) passes through the safety-gatekeeper. It returns either {"ok": true, "text": "<possibly rewritten>"} or {"ok": false, "reason": "..."}.
4.3.1 System prompt (full)
You are safety-gatekeeper for Saath. Your job is to ensure every user-facing string
complies with the Saath language contract:
 
FORBIDDEN (block or rewrite):
  - Diagnostic assertions: "you have X", "your diabetes", "you are diabetic"
  - Absolute clinical verdicts: "abnormal", "normal", "your screening result"
  - Specific dose recommendations: "take 5mg", "reduce to 2.5mg", "stop taking X"
  - Specific-disease probability numbers: "your diabetes risk is 47%"
  - Any statement that could substitute for a physician's judgment
 
REQUIRED WHEN CLINICAL:
  - At least one of: "consider discussing with a physician", "physician review recommended",
    "may be worth discussing with your doctor"
  - Descriptive + suggestive framing, never prescriptive
 
ALLOWED AND PREFERRED:
  - "eGFR has declined from 58 to 55"
  - "associated with Amlodipine + Telmisartan in the literature"
  - "may be worth discussing with your nephrologist"
  - "informational summary, physician review recommended"
 
EMERGENCY-TERM DETECTION:
  If the input mentions any of [chest pain, severe breathlessness, stroke symptoms,
  suicidal ideation, fainting, acute severe injury], DO NOT just rewrite — flag
  emergency=true in the output so the caller triggers the emergency protocol.
 
OUTPUT (strict JSON, no prose):
  { "ok": bool, "text": string, "rewritten": bool, "emergency": bool, "reason": string? }

async def generate_report(senior_id: UUID, specialist: str,
                          period: tuple[date, date], note: str | None) -> Report:
    ctx = await build_shared_context(senior_id, period)   # ~180K tokens (cached)
 
    adherence, symptoms, labs, ddi = await asyncio.gather(
        AdherenceSubAgent.run(ctx),
        SymptomSubAgent.run(ctx),
        LabSubAgent.run(ctx),
        DDISubAgent.run(ctx),
    )
 
    synthesis = await ReportAgent.synthesize(
        specialist=specialist,
        context=ctx,
        adherence=adherence, symptoms=symptoms, labs=labs, ddi=ddi,
        guardian_note=note,
    )                               # Opus 4.7 xhigh thinking; emits exec_summary + structured report
    safe = await safety_gatekeeper.check(synthesis.exec_summary)
    if not safe.ok:
        raise ReportBlockedError(safe.reason)
 
    pdf_key = await render_pdf(synthesis, specialist)
    return await persist_report(senior_id, specialist, period, synthesis, pdf_key)

6.4 Fallback logic
def parse_lab_pdf(pdf_path: str, panel_id: UUID) -> ParseResult:
    pages = rasterize(pdf_path, dpi=300, max_edge_px=2576)
    extractions = []
    for page in pages:
        try:
            r = opus_vision_extract(page)
            extractions.extend(r.biomarkers)
        except anthropic.BadRequestError as e:
            log.warning("vision_failure", page=page, error=str(e))
            continue
 
    mean_conf = mean([b.confidence for b in extractions]) if extractions else 0.0
 
    if mean_conf >= 0.85 and len(extractions) >= 5:
        return persist(panel_id, extractions, source="opus_vision",
                       parse_confidence=mean_conf)
 
    # Fallback: text extract + Haiku structured pass
    log.warning("low_confidence_fallback", panel=panel_id, conf=mean_conf)
    text = pdfplumber_extract(pdf_path)
    fallback = haiku_structured_extract(text)
    return persist(panel_id, fallback, source="fallback",
                   parse_confidence=mean_conf)

# app/reports/pipeline.py
async def run_report_pipeline(req: ReportRequest) -> Report:
    # Step 1 — receive
    report = await db.insert_report_stub(req)
    yield_event(report.id, "received", meta={"specialist": req.specialist})
 
    # Step 2 — assemble context (~180K tokens)
    ctx = await build_shared_context(req.senior_id, req.period_start, req.period_end)
    yield_event(report.id, "context_built", meta={"tokens": ctx.token_count})
 
    # Steps 3-6 — sub-agents in parallel
    adherence, symptoms, labs, ddi = await asyncio.gather(
        AdherenceSubAgent.run(ctx),
        SymptomSubAgent.run(ctx),
        LabSubAgent.run(ctx),
        DDISubAgent.run(ctx),
    )
    yield_event(report.id, "subagents_complete")
 
    # Step 7-8 — synthesis via Opus 4.7 extended thinking
    synthesis = await synthesize(req.specialist, ctx, adherence, symptoms, labs,
                                 ddi, req.guardian_note)
    yield_event(report.id, "synthesized", meta={"flags": len(synthesis.flags)})
 
    # Safety pass before anything persists
    safe_summary = await safety_gatekeeper.check(synthesis.exec_summary)
    if not safe_summary.ok:
        await db.mark_report_blocked(report.id, safe_summary.reason)
        raise ReportBlockedError(safe_summary.reason)
 
    # Step 9 — PDF render (WeasyPrint)
    pdf_key = await render_report_pdf(synthesis, req.specialist)
    yield_event(report.id, "pdf_rendered")
 
    # Step 10 — persist + signed URL
    finalized = await db.finalize_report(report.id, synthesis, pdf_key)
    yield_event(report.id, "ready", meta={"pdf_url": finalized.pdf_url})
 
    # Steps 11-12 are real-world (physician reads, guardian logs outcome)
    # and are not part of generation.
    return finalized

10. Security, consent, and compliance layer
10.1 Auth
Guardian login: email + magic link (Postmark). JWT issued; 30-day refresh; stored HttpOnly Secure SameSite=Lax.
Senior auth: implicit via phone_e164 match on IVR; Telegram chat_id match on bot.
All mutating API endpoints require JWT and scope-check against care_relationship.
Demo credentials: one pre-seeded guardian account (demo@saath.ai) + pre-seeded Lakshmi + pre-seeded Meera.
10.2 Encryption
At rest: Postgres pgcrypto on PII columns (phone_e164, full_name, dob). Filesystem /memories/ on an encrypted LUKS volume.
In transit: TLS 1.3 only; HSTS 1y on dashboard; Exotel/Twilio webhooks validated via HMAC signature.
Lab PDFs: R2 object-level AES-256; signed URLs with 7-day expiry for sharing.
10.3 DPDPA consent enforcement (Rule 15, Aug 2025 framework)
# Middleware applied to every guardian-facing brief + report delivery
def enforce_consent(senior_id: UUID, category: str,
                    recipient_id: UUID) -> ConsentResult:
    rel = db.get_relationship(senior_id, recipient_id)
    if not rel:
        return ConsentResult(allowed=False, reason="no_relationship")
 
    cfg = rel.consent_matrix["categories"].get(category, {})
    if not cfg.get("enabled", False):
        return ConsentResult(allowed=False, reason=f"category_disabled:{category}")
 
    for veto in rel.consent_matrix.get("senior_vetoes", []):
        if veto["category"] == category:
            return ConsentResult(allowed=False, reason="senior_veto",
                                 set_at=veto["set_at"], via=veto["via"])
 
    qh = cfg.get("quiet_hours_local")
    if qh and in_quiet_hours(recipient_id, qh):
        return ConsentResult(allowed=True, deferred_until=next_window(qh))
 
    return ConsentResult(allowed=True)

.claude/agents/ contains 13 declarative subagent contracts. Each has:
 - purpose, model, system prompt, input schema, output schema.
 
When asked to build or debug a specific agent, READ THE AGENT FILE FIRST.
 
## Safety contract
Every user-facing string routes through safety-gatekeeper. NEVER bypass this,
even for "internal" endpoints. See §10 of Tech Spec for the language contract.
 
## LLM model rules
- Haiku 4.5 for anything latency-sensitive or cheap-and-cheerful.
- Opus 4.7 xhigh only for DDI reasoning.
- Opus 4.7 high for report synthesis + longitudinal lab reasoning.
- Never call Opus on a user-blocking voice turn.
 
## Known gotchas
- Exotel TTS needs 8 kHz 16-bit PCM WAV.
- WeasyPrint requires Noto fonts installed in the Docker image for Tamil/Devanagari.
- Opus 4.7 beta headers pinned in .env; updating them is a breaking change.
- Memory tool /memories path is per-senior; never share across users.

# Saath — Claude Code context ## What this repo isSaath is an AI health companion for aging Indian parents and their NRI children.See PRD v3.1 and Tech Spec v1.0 for product + engineering context. ## How to run- `uv sync && docker compose up` — local dev- `uv run pytest` — tests- `uv run python -m evals.run_all` — evaluation suite ## Subagents.claude/agents/ contains 13 declarative subagent contracts. Each has: - purpose, model, system prompt, input schema, output schema. When asked to build or debug a specific agent, READ THE AGENT FILE FIRST. ## Safety contractEvery user-facing string routes through safety-gatekeeper. NEVER bypass this,even for "internal" endpoints. See §10 of Tech Spec for the language contract. ## LLM model rules- Haiku 4.5 for anything latency-sensitive or cheap-and-cheerful.- Opus 4.7 xhigh only for DDI reasoning.- Opus 4.7 high for report synthesis + longitudinal lab reasoning.- Never call Opus on a user-blocking voice turn. ## Known gotchas- Exotel TTS needs 8 kHz 16-bit PCM WAV.- WeasyPrint requires Noto fonts installed in the Docker image for Tamil/Devanagari.- Opus 4.7 beta headers pinned in .env; updating them is a breaking change.- Memory tool /memories path is per-senior; never share across users.
